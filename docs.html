📖 System Guide & Terminal Instructions

User manual for running the Interactive Web App, Terminal CLI, Desktop GUI, and Test Suite

🚀 Quick Start Commands

1. Interactive Terminal CLI

Launches the formatted command-line interface with ASCII Gantt charts and statistical tables:

python cli.py

2. Automated Comparative Simulation (CLI Mode)

Runs a head-to-head comparison between fixed burst and variable burst workloads:

python cli.py --compare --sim-time 60 --processes 8

3. Tkinter Desktop GUI

Launches the standalone visual desktop application with Canvas Gantt charts and side-by-side metric visualizer:

python gui.py

4. Automated Unit Test Suite

Runs full test coverage verifying quantum slicing, priority demotion, Round Robin ordering, and horizon cutoffs:

python -m unittest test_mlfq.py -v

5. Local HTTP Web Server

Serves the multi-page web application locally on port 8080:

python -m http.server 8080
